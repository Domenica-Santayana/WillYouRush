# WillYouRush

Will You Rush is a quick WarioWare style game which was made using the Godot Engine. It features 2 games with levels that will make you defy your speed at making 2 different tasks.

## Game Structure
1. **Title Screen:** Start screen to start the game. (Originally done with canva)
2. **Whack a Mole (Level 1):** Just as the famous game Whack a Mole, you will need to catch moles, yet here's the catch: you should catch a required number of moles (20 moles) before time runs out (15 seconds).
3. **Quiz:** You will have 5 seconds to answer each question, featuring some arithmetic and calculus.
4. **Whack a Mole (Level 2):** So, just as before, you have got Will You Rush version of Whack a Mole yet it's a harder level because of the time limit cut in half: now you've got 10 seconds to catch 20 moles.
5. **Game over/Victory:** 2 personalised screens made by myself will appear either if you win or lose any of the games. Each option has a button to try again or start the game again.
   
_Note: You should know that if you lose any of the games you will inmediately go back to the start of the whole game._

## Features
* **Title Screen:** Personalised by me and made on canva plus some other online website for the creation of graphics.
* **Personalised Sprites:** Both the moles, the tubes and the clock logotype were all made by hand using pixel art technique.
* **Personalised Screens:** Game Over and victory screens, plus instruction panels for each minigame.

## How to use it
* Use your mouse to left-click on the moles and select the correct answers as quickly as possible.
* Buttons of try again and start the game will appear, just left-click the letters
